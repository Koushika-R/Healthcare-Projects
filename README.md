# Healthcare Projects
Basic data science projects based on the healthcare domain. The datasets used are obtained from Kaggle.

TASK 1_Healthcare Dataset - It is a synthetic dataset. Performed basic EDA, visualization, encoding, and applied a Random Forest Classifier on the dataset for three-class classification.

Task 2_Pima Indians Diabetes Database - The workflow began with data preprocessing, including handling missing values, and addressing skewness through appropriate transformations to improve model performance. Three classification models— Logistic Regression, KNN, and Decision Tree—were developed and evaluated.

Task 3_Breast Cancer Wisconsin (Diagnostic) Dataset - This project applies a simple neural network (TensorFlow/Keras) to classify breast cancer tumors as benign or malignant using the Breast Cancer Wisconsin dataset. The model was trained on 30 diagnostic features and achieved ~97% accuracy on the test set.

Task 4_scRNA-seq: Cancer Microenvironment Classification - This project analyzes a synthetic single-cell RNA-seq tumor microenvironment dataset from Kaggle using Python. It demonstrates key single-cell analysis techniques, including cell type classification, biomarker discovery, and differential gene expression. Random Forest model and visualization methods like PCA and UMAP are applied to explore cellular heterogeneity and identify potential therapeutic targets.
